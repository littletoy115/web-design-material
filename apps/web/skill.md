## 5. Design / Technical Observations (analysis, not stated on site)

- Content pattern: alternating feature sections, each pairing a bold two-line heading with one short sentence — very low text density, media-first.
- Uses short looping `.mp4` videos instead of GIFs for feature demos (better compression/quality).
- Asset paths follow a clean convention: `/assets/img/<section>/<n>.png`, `/assets/video/<section>/1.mp4`.
- Headings often split across lines for visual rhythm (e.g., "Layer / it up", "Make / it sing!").
- Social proof is outbound-link based (real user posts), not embedded — fast page load, authentic feel.
